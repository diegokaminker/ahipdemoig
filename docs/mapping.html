Mapping

Mapping

This page describes mappings between this Implementation Guide's artifacts and related code systems or other IGs, where applicable.

Purpose

Mappings support implementers who need to:

  • Crosswalk between AHIP Demo value sets and existing terminologies (e.g., OMB race/ethnicity, CDC, LOINC, SNOMED CT).
  • Align with other FHIR IGs (e.g., US Core extensions or value set bindings).
  • Support reporting or analytics that require specific code systems.

Current status

[Placeholder.] Formal mapping tables (e.g., AHIP Demo codes to OMB, CDC, or US Core) will be added as they are developed and balloted. The DEMo Initiative and AHIP Health Equity Workgroup have documented alignment with national questionnaires and cognitive testing; those alignments may be reflected here or in separate DEMo deliverables.

How to use mappings

  • From this IG to external systems: Use the mapping (when published) to translate values collected with this IG's value sets into the codes required by a downstream system or measure.
  • From external systems to this IG: Use the inverse mapping to populate this IG's value sets from legacy or external code systems, where equivalence is defined.

Feedback

If you have proposed mappings or find errors in mapping tables, please submit feedback via Support (Propose a Change) or the project's issue tracker.
