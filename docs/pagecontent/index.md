## Plain Language Description

The AHIP Demographics Implementation Guide (AHIP Demo IG) supports the collection and exchange of standardized demographic data to advance health equity. It provides:

- **Standardized data elements** for race and ethnicity (including granular background categories), sexual orientation and gender identity, preferred language (speaking and reading), disability status, military experience, and religion or spirituality.
- **FHIR-based artifacts**—value sets, code systems, and a questionnaire—so that health plans, providers, and other organizations can collect and share demographic information in a consistent, interoperable way.
- **Alignment with the DEMo Initiative** (Demographic Data Element Modernization), a partnership of AHIP, Civitas Networks for Health, and HL7, aimed at modernizing demographic standards so that data is accurate, complete, comparable, and actionable.

The Guide is intended for use by health plans, providers, health information exchanges, and third-party applications that need to collect or consume demographic data for quality measurement, disparity analysis, and culturally responsive care.
