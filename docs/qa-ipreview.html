  • AHIP, Civitas Networks for Health (Civitas), and Health Level Seven International® (HL7®) launched the Demographic Data Element Modernization (DEMo) Initiative in late 2023. The initiative aims to improve existing and develop new demographic data standards so that health care organizations can better leverage such data to identify disparities, inform culturally responsive care, and improve health outcomes. This multi-phased, multi-stakeholder collaboration began with national focus groups that brought together over 130 diverse organizations to develop enhanced demographic questions and response options, which later underwent cognitive testing and refinements. This Implementation Guide (IG) supports the DEMo Initiative by translating the initiative's refined questions and response options into interoperable, production-ready HL7 standards and implementation guidance. web civitasforhealth.org We note that the Questionnaire underwent cognitive testing with patients as a complete instrument. Testing showed that patients largely understood what was being asked of them, were comfortable answering the questions, and that they felt represented by the response options. The Questionnaire is structured such that those administering it can choose the level of detail—some questions are listed as optional and, in some cases, the granular level detail can be rolled up to higher level categories so that regardless of the level of detail collected the information can be compared across locations. However, the Questionnaire is designed to be given as is and in whole; if a site choses to use only certain questions, change the wording of the question, select only certain response choices, or use only the compiled value sets, we recommend the site further test for validity and accuracy of the results.
